# سیستم جامع و هیجان‌انگیز رونمایی از ۱۰ تیم برتر مسابقه (Top 10 Ceremony Showcase)

یک سیستم حرفه‌ای، تعاملی، سینمایی و زنده برای آیین اختتامیه مسابقات، رویدادهای فناوری، برنامه‌نویسی و المپیادها. طراحی‌شده برای نمایش روی ویدیو پروژکتور، نمایشگرهای Full HD و 4K بدون هیچ‌گونه نیاز به تغییر کد در هنگام ورود نتایج داوری.

---

## 🌟 ویژگی‌های کلیدی سیستم

### ۱. معماری تفکیک‌شده دوگانه (Dual Architecture)
- **اتاق فرمان و پنل مدیریت مجری (Admin Panel):**
  - جدول ورود و ویرایش نتایج با اعتبارسنجی آنی ۱۰ تیم
  - امکان ورود گروهی با فایل یا متن **CSV** و **JSON**
  - تنظیم زمان‌بندی تعلیق، شمارش معکوس، مدت اسکرول و توقف کارت‌ها
  - تنظیم رنگ‌بندی و تم‌های بصری (آبی سایبری، طلایی سلطنتی، زمردی، بنفش نئونی)
  - کنترل کامل پخش: شروع، توقف/ادامه، گام بعد، گام قبل، تکرار مرحله، رونمایی فوری، پرش به جدول نهایی
  - پشتیبانی از اتصال به نمایشگر دوم (پروژکتور) با دکمه اختصاصی `پنجره نمایش پروژکتور` (`?mode=stage`)
- **صحنه نمایش اختتامیه (Ceremony Stage):**
  - خروجی کاملاً خالص و سینمایی بدون هیچ دکمه فنی یا نوار ابزار در دید تماشاچیان
  - نسبت تصویر ۱۶:۹ با ابعاد واکنش‌گرا و فضای امن برای خوانایی از فاصله دور
  - پس‌زمینه پویا با سیستم ذرات شناور کانواس (Canvas Particles) و تابش‌های حجمی

### ۲. توالی و سناریوی رسمی مراسم (State Machine)
1. **مرحله صفر (Idle):** صفحه خوش‌آمدگویی و انتظار برای فرمان آغاز با عنوان رویداد و پیام «آماده‌اید؟».
2. **مرحله اول (Intro & Countdown):** پخش افکت آغازین، تیتراژ «۱۰ تیم برتر مسابقه» و شمارش معکوس پرهیجان (۵ تا ۱).
3. **مرحله دوم (رونمایی رتبه‌های ۱۰ تا ۳):**
   - اسکرول سریع نام‌ها در یک شکاف هدف نوری با افکت Motion Blur و تیک‌های مکانیکی
   - کاهش تدریجی سرعت اسکرول و اوج‌گیری رایزر تعلیق
   - مکث نهایی ناگهانی برای حبس نفس تماشاچیان
   - ضربه صوتی سنگین، نمایش رتبه با پلاک متالیک، نام تیم و شمارشگر متحرک امتیاز واقعی
4. **مرحله سوم (فینال طلایی ۲ تیم برتر):**
   - تابلوی تعلیق فینال: «تنها دو تیم باقی مانده‌اند...»
   - **رونمایی اول:** رونمایی باشکوه از **تیم قهرمان (رتبه ۱)** با تم طلایی، تاج و نشان زرین، نورافشانی، آتش‌بازی کنفتی و مارش پیروزی!
   - **رونمایی دوم:** رونمایی ویژه از **تیم نایب‌قهرمان (رتبه ۲)** با تم نقره‌ای متالیک، مدال و مارش ترومپت نقره‌ای!
   *(قابلیت تغییر به ترتیب سنتی در تنظیمات نیز فراهم است)*
5. **مرحله چهارم (جدول نهایی Final Table):** ورود تدریجی و هماهنگ جدول رده‌بندی کامل هر ۱۰ تیم، با تمایز جایگاه اول، دوم و سوم.

### ۳. موتور صوتی استودیویی کاملاً مستقل (Web Audio API)
- تولید ۱۰۰٪ آفلاین صداها بدون نیاز به فایل‌های خارجی یا دانلود اینترنتی (بدون خطای ۴۰۴ یا تأخیر بارگذاری)
- کانال‌های مجزای کنترل شدت صدا: **صدای کلی (Master)**، **افکت‌ها و ضربه‌ها (SFX)** و **موسیقی و فضاپردازی (Music)**
- کلید قطع و وصل صدا (Mute)
- میز آزمایش و تست زنده تک‌تک افکت‌های صوتی در پنل مدیریت

## ⌨️ کلیدهای میانبر مجری (Live Hotkeys)

| کلید میانبر | عملکرد |
|---|---|
| `Space` | توقف موقت / ادامه اجرای مراسم (یا شروع از صفحه اول) |
| `→` (Arrow Right) | رفتن به مرحله بعدی مراسم |
| `←` (Arrow Left) | بازگشت به مرحله قبلی مراسم |
| `R` | تکرار و اجرای مجدد مرحله جاری |
| `M` | قطع / وصل کامل صدا (Mute Toggle) |
| `F` | ورود / خروج از حالت تمام‌صفحه (Fullscreen) |
| `Esc` | بازگشت از صحنه نمایش به پنل مدیریت |

*(میانبرها در حین تایپ درون کادرهای متنی غیرفعال می‌شوند تا تداخلی ایجاد نشود).*

## 🚀 راهنمای نصب و اجرای پروژه

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm نسخه 9 یا بالاتر

### ۱. اجرای سرور توسعه محلی:
```bash
npm run dev
```
سپس مرورگر خود را در آدرس `http://localhost:5173` باز کنید.

### ۲. ساخت نسخه نهایی برای مراسم (Build):
```bash
npm run build
npm run preview
```

### ۳. اجرای تست‌های اعتبارسنجی و منطق توالی:
```bash
npm test
```

## 🖥️ راهنمای اتصال به ویدیو پروژکتور و نمایشگر دوم

1. سیستم خود را با کابل HDMI یا بی‌سیم به پروژکتور متصل کنید و در ویندوز حالت نمایش را روی **Extend (گسترش نمایشگر)** بگذارید (`Win + P`).
2. در پنل مدیریت، روی دکمه **«پنجره نمایش پروژکتور»** کلیک کنید.
3. یک پنجره جدید باز می‌شود؛ آن پنجره را به صفحه پروژکتور بکشید و کلید `F` را فشار دهید تا تمام‌صفحه شود.
4. اکنون شما در مانیتور لپ‌تاپ خود تمام پنل مدیریت و کنترل‌ها را دارید، و تماشاچیان روی پرده فقط صحنه سینمایی و بدون دکمه اختتامیه را مشاهده می‌کنند!
5. هر فرمانی (شروع، مرحله بعد، توقف و...) در مانیتور شما، بلافاصله روی نمایشگر پروژکتور اعمال می‌شود.

```json
      "score": 98.75,
      "org": "دانشگاه صنعتی شریف",
      "members": "سهراب مرادی، نیلوفر راد"
```

```csv
rank,name,score,org,members
1,ققنوس سایبری,98.75,دانشگاه صنعتی شریف,سهراب مرادی
2,داده‌کاوان البرز,96.50,دانشگاه تهران,پارسا معتمدی
```

*(سیستم به صورت خودکار سرستون‌های انگلیسی و فارسی مانند `رتبه`، `نام` و `امتیاز` را شناسایی می‌کند).*

## 🔒 قوانین اعتبارسنجی داده‌ها
- تعداد تیم‌ها باید دقیقاً **۱۰ تیم** باشد.
- رتبه‌ها باید یکتا و ارقام ۱ تا ۱۰ باشند.
- نام هیچ تیمی نمی‌تواند خالی باشد.
- امتیازات باید عددی معتبر باشند (پشتیبانی کامل از ارقام اعشاری).
- امکان محاسبه خودکار رتبه‌ها بر اساس مرتب‌سازی بیشترین امتیاز در پنل مدیریت با یک کلیک فراهم است.
